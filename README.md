# GALA: Glossary-Aware Legal Agent
Questa repository contiene il codice per costuire un sistema RAG agentico basato su LLM locali (<10B parametri) specializzato nel dominio legale. Le performance del modello sono ottimizzate e allineate a un glossario tecnico-giuridico attraverso tecniche di Reinforcement Learning.
